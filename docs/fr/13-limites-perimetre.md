# Chapitre 13 -- Limites et perimetre de ce parcours

Ce parcours couvre l architecture centrale du package account-sdk tel qu il existe dans le depot base/account-sdk a la date du clone : le provider EIP-1193 complet (BaseAccountProvider, Signer), son infrastructure de communication chiffree (Communicator, SCWKeyManager, cipher.ts), les sous-comptes et leur financement, et les deux API de paiement autonomes, Base Pay et Base Subscriptions, avec leur provider ephemere dedie.

Sont volontairement laisses hors champ : le package account-ui (les composants d interface graphique de la popup et des dialogues, qui relevent du rendu plutot que du protocole) ; le package account-cli ; l application d exemple testapp ; le detail complet du module kms/crypto-key au-dela de son usage comme source de cle proprietaire pour les sous-comptes ; l integration profonde avec viem au-dela des points d encodage cites dans les chapitres precedents ; et le detail exhaustif de chaque evenement de telemetrie emis a travers le SDK, mentionne au passage mais non explique fonction par fonction.

L objectif reste le meme que pour les parcours precedents de cette bibliotheque : donner une comprehension solide et verifiee du mecanisme central -- ici, comment une application web etablit un canal chiffre de bout en bout avec un wallet Base Account via une simple popup et l API Web Crypto du navigateur, et comment ce meme canal sert aussi bien une connexion de compte complete qu un paiement ou un abonnement ponctuel sans configuration prealable -- sans pretendre couvrir l integralite de l ecosysteme account-sdk.
